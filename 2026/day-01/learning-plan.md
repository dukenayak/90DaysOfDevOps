What is your understanding of DevOps and Cloud Engineering?
I think to understand this we need to understand both the terms separately.
First.
What is Devops?
DevOps is a set of practices and a culture that bring software development (Dev) and IT operations (Ops) together, with the goal of shipping software faster and more reliably.
Then.
What is Cloud Engineering?
Cloud Engineering is about designing, building, and operating the infrastructure that applications run on top of, using a cloud provider's building blocks (AWS, GCP, Azure).
In technical terms we can say
DevOps is about the delivery pipeline — how code goes from a developer's machine to production, fast and safely. It covers CI/CD automation, release/rollback strategy, and the culture of dev and ops teams sharing ownership instead of working in silos.

Cloud Engineering is about the infrastructure itself — designing and building the compute, networking, storage, and security that applications run on, using a cloud provider (AWS/GCP/Azure). It covers Infrastructure as Code (Terraform, CloudFormation), architecture decisions (VPCs, HA/multi-region design), and cost/security management.
